# MERCURY Servicios Digitales — starter
Este es un punto de partida visual con React, Vite y Supabase; no es una tienda terminada ni está publicada.
1. Descomprime el ZIP en un entorno con Node.js.
2. Copia `.env.example` como `.env`.
3. Coloca la URL del proyecto en `VITE_SUPABASE_URL` y la clave publicable en `VITE_SUPABASE_ANON_KEY`.
4. Ejecuta `npm install` y `npm run dev`.
Nunca incluyas claves secret o service_role en el navegador. Antes de producción deben completarse autenticación, carrito, pedidos con validación del lado servidor, comprobantes, almacenamiento privado y panel administrativo. Revisa y endurece las políticas RLS existentes antes de producción.
